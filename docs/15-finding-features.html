When you cannot find it

  1. Check you are on the Plus binary if you are looking for nRF24.
  2. Confirm the SD card is mounted.
  3. Reboot after copying large packs.
  4. Look in Config / Settings for optional items.
  5. Check the project’s GitHub releases and Discord for version-specific changes.

Menu maps go out of date. The groups stay stable even when individual labels move.
