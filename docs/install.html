Install Remote Guide

Web flash

Install from this page's flashers.

Desktop Chrome or Edge. USB-C data cable. Click the encoder if the screen is dark. The board enters download mode on its own. Pick Plus only when the flasher has a Plus row; otherwise the CC1101 build is the one both boards take, and nRF24 needs the Plus asset when a project ships one.

  1. Charge the board. FAT32 card, 16 or 32 GB, if you want slots.
  2. Flash one launcher. Not both. The second erase replaces the first.
  3. Flash Bruce alone only if you do not want to switch apps.
  4. Copy other .bin files to the card and install them into slots on the device.
